<h3 id="tinh-chat">📖 1. Tính chất của dãy tỉ số bằng nhau</h3>

<div class="box-dinh-ly">

**Tính chất:** Từ dãy tỉ số bằng nhau:

$$\frac{a}{b} = \frac{c}{d}$$

Ta có:

$$\frac{a}{b} = \frac{c}{d} = \frac{a + c}{b + d} = \frac{a - c}{b - d}$$

(với điều kiện các mẫu số khác 0 và $b \neq d$ trong trường hợp trừ)

</div>

**Chứng minh:**

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

Đặt $\frac{a}{b} = \frac{c}{d} = k$

Suy ra: $a = bk$ và $c = dk$

Ta có:

$\frac{a + c}{b + d} = \frac{bk + dk}{b + d} = \frac{k(b + d)}{b + d} = k$

$\frac{a - c}{b - d} = \frac{bk - dk}{b - d} = \frac{k(b - d)}{b - d} = k$

Vậy $\frac{a}{b} = \frac{c}{d} = \frac{a + c}{b + d} = \frac{a - c}{b - d} = k$

</div>

**Ví dụ 1:** Cho $\frac{3}{4} = \frac{6}{8}$. Kiểm tra tính chất.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

$\frac{3}{4} = \frac{6}{8} = 0.75$

$\frac{3 + 6}{4 + 8} = \frac{9}{12} = 0.75$ ✓

$\frac{3 - 6}{4 - 8} = \frac{-3}{-4} = 0.75$ ✓

</div>

<h3 id="mo-rong" style="margin-top:2rem;">📖 2. Tính chất mở rộng</h3>

<div class="box-dinh-ly">

**Tính chất mở rộng:** Từ dãy tỉ số bằng nhau:

$$\frac{a}{b} = \frac{c}{d} = \frac{e}{f}$$

Ta có:

$$\frac{a}{b} = \frac{c}{d} = \frac{e}{f} = \frac{a + c + e}{b + d + f} = \frac{a - c + e}{b - d + f}$$

(với điều kiện các mẫu số khác 0)

</div>

**Ví dụ 2:** Cho $\frac{2}{3} = \frac{4}{6} = \frac{6}{9}$. Tính $\frac{2 + 4 + 6}{3 + 6 + 9}$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

Theo tính chất mở rộng:

$\frac{2 + 4 + 6}{3 + 6 + 9} = \frac{2}{3} = \frac{4}{6} = \frac{6}{9} = \frac{2}{3}$

Kiểm tra: $\frac{12}{18} = \frac{2}{3}$ ✓

</div>

<h3 id="ung-dung" style="margin-top:2rem;">📖 3. Ứng dụng: Tìm số chưa biết</h3>

**Phương pháp:** Đặt các tỉ số bằng $k$, biểu diễn các số theo $k$, rồi giải phương trình.

**Ví dụ 3:** Tìm $x, y$ biết $\frac{x}{3} = \frac{y}{5}$ và $x + y = 24$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

Đặt $\frac{x}{3} = \frac{y}{5} = k$

Suy ra: $x = 3k$ và $y = 5k$

Thay vào điều kiện: $x + y = 24$

$3k + 5k = 24$

$8k = 24$

$k = 3$

Vậy: $x = 3 \times 3 = 9$ và $y = 5 \times 3 = 15$

</div>

**Ví dụ 4:** Tìm $x, y, z$ biết $\frac{x}{2} = \frac{y}{3} = \frac{z}{5}$ và $x + y + z = 50$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

Đặt $\frac{x}{2} = \frac{y}{3} = \frac{z}{5} = k$

Suy ra: $x = 2k$, $y = 3k$, $z = 5k$

Thay vào điều kiện: $x + y + z = 50$

$2k + 3k + 5k = 50$

$10k = 50$

$k = 5$

Vậy: $x = 10$, $y = 15$, $z = 25$

</div>

**Ví dụ 5:** Tìm $a, b$ biết $\frac{a}{4} = \frac{b}{7}$ và $a - b = 9$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

Đặt $\frac{a}{4} = \frac{b}{7} = k$

Suy ra: $a = 4k$ và $b = 7k$

Thay vào điều kiện: $a - b = 9$

$4k - 7k = 9$

$-3k = 9$

$k = -3$

Vậy: $a = 4 \times (-3) = -12$ và $b = 7 \times (-3) = -21$

</div>

<h3 id="bai-toan-chia-ti-le" style="margin-top:2rem;">📖 4. Bài toán chia tỉ lệ</h3>

**Dạng bài:** Chia một số thành các phần tỉ lệ với các số cho trước.

**Ví dụ 6:** Chia số 120 thành ba phần tỉ lệ với 2, 3, 5.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

Gọi ba phần cần tìm là $x, y, z$.

Theo đề bài: $\frac{x}{2} = \frac{y}{3} = \frac{z}{5}$ và $x + y + z = 120$

Đặt $\frac{x}{2} = \frac{y}{3} = \frac{z}{5} = k$

Suy ra: $x = 2k$, $y = 3k$, $z = 5k$

Từ $x + y + z = 120$:

$2k + 3k + 5k = 120$

$10k = 120$

$k = 12$

Vậy: $x = 24$, $y = 36$, $z = 60$

</div>

<h3 id="cac-dang-toan">🧩 II. Các dạng toán và Phương pháp giải</h3>

<h4 id="dang-1">Dạng 1: Tìm hai số biết tỉ số và tổng (hoặc hiệu) của chúng</h4>

**Phương pháp:** 
Sử dụng tính chất của dãy tỉ số bằng nhau:
- Nếu $\dfrac{x}{a} = \dfrac{y}{b}$ thì $\dfrac{x}{a} = \dfrac{y}{b} = \dfrac{x + y}{a + b} = \dfrac{x - y}{a - b}$

**Ví dụ 1.1:** Tìm hai số $x, y$ biết $\dfrac{x}{3} = \dfrac{y}{5}$ và $x + y = 32$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Áp dụng tính chất dãy tỉ số bằng nhau:
$\dfrac{x}{3} = \dfrac{y}{5} = \dfrac{x + y}{3 + 5} = \dfrac{32}{8} = 4$.
Suy ra $x = 3 \cdot 4 = 12$; $y = 5 \cdot 4 = 20$.
</details>

**Ví dụ 1.2:** Tìm hai số $a, b$ biết $a : b = 7 : 4$ và $a - b = 15$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Từ $a : b = 7 : 4$, ta có $\dfrac{a}{7} = \dfrac{b}{4}$.
Áp dụng tính chất dãy tỉ số bằng nhau:
$\dfrac{a}{7} = \dfrac{b}{4} = \dfrac{a - b}{7 - 4} = \dfrac{15}{3} = 5$.
Do đó $a = 7 \cdot 5 = 35$; $b = 4 \cdot 5 = 20$.
</details>

**Ví dụ 1.3:** Tìm $x, y$ biết $2x = 5y$ và $x + y = -14$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Từ $2x = 5y$, ta suy ra $\dfrac{x}{5} = \dfrac{y}{2}$.
Áp dụng tính chất dãy tỉ số bằng nhau:
$\dfrac{x}{5} = \dfrac{y}{2} = \dfrac{x + y}{5 + 2} = \dfrac{-14}{7} = -2$.
Vậy $x = 5 \cdot (-2) = -10$; $y = 2 \cdot (-2) = -4$.
</details>

**Bài toán thực tế 1.1:** Hai lớp 7A và 7B quyên góp được tổng cộng 120 quyển vở. Số vở lớp 7A quyên góp tỉ lệ với 5, số vở lớp 7B quyên góp tỉ lệ với 7. Tính số vở mỗi lớp đã quyên góp.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số vở lớp 7A và 7B quyên góp lần lượt là $x, y$ ($x,y > 0$).
Ta có $\dfrac{x}{5} = \dfrac{y}{7}$ và $x + y = 120$.
Áp dụng tính chất: $\dfrac{x}{5} = \dfrac{y}{7} = \dfrac{x + y}{5 + 7} = \dfrac{120}{12} = 10$.
Số vở lớp 7A: $x = 50$ (quyển). Số vở lớp 7B: $y = 70$ (quyển).
</details>

**Bài toán thực tế 1.2:** Một khu vườn hình chữ nhật có tỉ số giữa chiều dài và chiều rộng là $\dfrac{4}{3}$. Biết chiều dài hơn chiều rộng 12 m. Tính chiều dài và chiều rộng của khu vườn.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi chiều dài là $a$ (m), chiều rộng là $b$ (m) ($a,b > 0$).
Ta có $\dfrac{a}{b} = \dfrac{4}{3} \Rightarrow \dfrac{a}{4} = \dfrac{b}{3}$ và $a - b = 12$.
Áp dụng tính chất: $\dfrac{a}{4} = \dfrac{b}{3} = \dfrac{a - b}{4 - 3} = \dfrac{12}{1} = 12$.
Chiều dài $a = 48$ m, chiều rộng $b = 36$ m.
</details>

**Bài toán thực tế 1.3:** Số bi của Minh và An có tỉ số là $5 : 2$. Biết rằng Minh có nhiều hơn An 15 viên bi. Hỏi mỗi bạn có bao nhiêu viên bi?

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số bi của Minh là $x$, số bi của An là $y$.
Ta có $\dfrac{x}{5} = \dfrac{y}{2}$ và $x - y = 15$.
Áp dụng tính chất: $\dfrac{x}{5} = \dfrac{y}{2} = \dfrac{x - y}{5 - 2} = \dfrac{15}{3} = 5$.
Minh có $x = 25$ viên bi. An có $y = 10$ viên bi.
</details>

<h4 id="dang-2">Dạng 2: Tìm ba số khi biết dãy tỉ số bằng nhau và biểu thức liên hệ</h4>

**Phương pháp:** 
- Viết dãy tỉ số $\dfrac{x}{a} = \dfrac{y}{b} = \dfrac{z}{c}$.
- Áp dụng tính chất: $\dfrac{x}{a} = \dfrac{y}{b} = \dfrac{z}{c} = \dfrac{x+y+z}{a+b+c} = \dfrac{x-y+z}{a-b+c} = \dots$ tuỳ theo biểu thức đề bài cho.

**Ví dụ 2.1:** Tìm $x, y, z$ biết $\dfrac{x}{2} = \dfrac{y}{3} = \dfrac{z}{4}$ và $x + y + z = 45$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Áp dụng tính chất dãy tỉ số bằng nhau:
$\dfrac{x}{2} = \dfrac{y}{3} = \dfrac{z}{4} = \dfrac{x+y+z}{2+3+4} = \dfrac{45}{9} = 5$.
Vậy $x = 10, y = 15, z = 20$.
</details>

**Ví dụ 2.2:** Tìm $x, y, z$ biết $x:y:z = 3:4:5$ và $x - y + z = 16$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Ta có $\dfrac{x}{3} = \dfrac{y}{4} = \dfrac{z}{5}$.
Áp dụng tính chất: $\dfrac{x}{3} = \dfrac{y}{4} = \dfrac{z}{5} = \dfrac{x - y + z}{3 - 4 + 5} = \dfrac{16}{4} = 4$.
Vậy $x = 12, y = 16, z = 20$.
</details>

**Ví dụ 2.3:** Tìm $a, b, c$ biết $\dfrac{a}{2} = \dfrac{b}{3}$, $\dfrac{b}{4} = \dfrac{c}{5}$ và $a + b - c = 10$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Ta có: $\dfrac{a}{2} = \dfrac{b}{3} \Rightarrow \dfrac{a}{8} = \dfrac{b}{12}$. Lại có $\dfrac{b}{4} = \dfrac{c}{5} \Rightarrow \dfrac{b}{12} = \dfrac{c}{15}$.
Vậy $\dfrac{a}{8} = \dfrac{b}{12} = \dfrac{c}{15}$.
Áp dụng tính chất: $\dfrac{a}{8} = \dfrac{b}{12} = \dfrac{c}{15} = \dfrac{a+b-c}{8+12-15} = \dfrac{10}{5} = 2$.
Suy ra $a = 16, b = 24, c = 30$.
</details>

**Bài toán thực tế 2.1:** Ba lớp 7A, 7B, 7C trồng được tổng cộng 120 cây. Số cây trồng được của 3 lớp lần lượt tỉ lệ với 3; 4; 5. Tính số cây mỗi lớp trồng được.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số cây của 7A, 7B, 7C là $x,y,z$. Ta có $\dfrac{x}{3} = \dfrac{y}{4} = \dfrac{z}{5}$ và $x+y+z = 120$.
$\dfrac{x}{3} = \dfrac{y}{4} = \dfrac{z}{5} = \dfrac{120}{12} = 10$.
Số cây lớp 7A là 30, lớp 7B là 40, lớp 7C là 50.
</details>

**Bài toán thực tế 2.2:** Một tam giác có chu vi là 36 cm. Biết độ dài 3 cạnh của tam giác đó tỉ lệ với 3, 4, 5. Tính độ dài các cạnh của tam giác.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi 3 cạnh là $a,b,c$. $\dfrac{a}{3} = \dfrac{b}{4} = \dfrac{c}{5}$ và $a+b+c=36$.
$\dfrac{a}{3} = \dfrac{b}{4} = \dfrac{c}{5} = \dfrac{36}{12} = 3$.
Các cạnh lần lượt là $9\text{ cm}, 12\text{ cm}, 15\text{ cm}$.
</details>

**Bài toán thực tế 2.3:** Số học sinh giỏi của 3 khối 6, 7, 8 tỉ lệ với 4, 3, 2. Khối 6 có nhiều hơn khối 8 là 30 học sinh giỏi. Tìm số học sinh giỏi của mỗi khối.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số học sinh giỏi khối 6, 7, 8 là $x,y,z$. Ta có $\dfrac{x}{4} = \dfrac{y}{3} = \dfrac{z}{2}$ và $x - z = 30$.
$\dfrac{x}{4} = \dfrac{y}{3} = \dfrac{z}{2} = \dfrac{x - z}{4 - 2} = \dfrac{30}{2} = 15$.
Khối 6: $4 \cdot 15 = 60$; Khối 7: $3 \cdot 15 = 45$; Khối 8: $2 \cdot 15 = 30$.
</details>

<h4 id="dang-3">Dạng 3: Bài toán mở rộng với biểu thức phức tạp</h4>

**Phương pháp:** 
Khi biểu thức điều kiện có dạng $c_1 x + c_2 y + c_3 z$, ta nhân (hoặc chia) tử và mẫu của các tỉ số với các hệ số tương ứng rồi mới cộng, trừ:
Ví dụ: $\dfrac{x}{a} = \dfrac{y}{b} \Rightarrow \dfrac{2x}{2a} = \dfrac{3y}{3b} = \dfrac{2x + 3y}{2a + 3b}$.

**Ví dụ 3.1:** Tìm $x, y$ biết $\dfrac{x}{2} = \dfrac{y}{5}$ và $2x - y = 12$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Ta có $\dfrac{x}{2} = \dfrac{y}{5} \Rightarrow \dfrac{2x}{4} = \dfrac{y}{5}$.
Áp dụng tính chất: $\dfrac{2x}{4} = \dfrac{y}{5} = \dfrac{2x - y}{4 - 5} = \dfrac{12}{-1} = -12$.
Vậy $\dfrac{x}{2} = -12 \Rightarrow x = -24$; $\dfrac{y}{5} = -12 \Rightarrow y = -60$.
</details>

**Ví dụ 3.2:** Tìm $a, b, c$ biết $\dfrac{a}{3} = \dfrac{b}{4} = \dfrac{c}{2}$ và $a + 2b - 3c = 25$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
$\dfrac{a}{3} = \dfrac{2b}{8} = \dfrac{3c}{6} = \dfrac{a + 2b - 3c}{3 + 8 - 6} = \dfrac{25}{5} = 5$.
$a = 15; b = 20; c = 10$.
</details>

**Ví dụ 3.3:** Tìm $x,y$ biết $\dfrac{x}{4} = \dfrac{y}{5}$ và $x \cdot y = 80$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Đặt $\dfrac{x}{4} = \dfrac{y}{5} = k$. Khi đó $x = 4k, y = 5k$.
$x \cdot y = 4k \cdot 5k = 20k^2 = 80 \Rightarrow k^2 = 4 \Rightarrow k = \pm 2$.
Nếu $k = 2$, $x = 8, y = 10$.
Nếu $k = -2$, $x = -8, y = -10$.
</details>

**Bài toán thực tế 3.1:** Số máy cày của ba đội I, II, III tỉ lệ với 4, 5, 6. Biết rằng hai lần số máy cày của đội I cộng với ba lần số máy cày đội II thì nhiều hơn số máy cày đội III là 34 máy. Tìm số máy cày của mỗi đội.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số máy cày là $x,y,z$. Ta có $\dfrac{x}{4} = \dfrac{y}{5} = \dfrac{z}{6}$ và $2x + 3y - z = 34$.
$\dfrac{2x}{8} = \dfrac{3y}{15} = \dfrac{z}{6} = \dfrac{2x+3y-z}{8+15-6} = \dfrac{34}{17} = 2$.
$x = 8, y = 10, z = 12$.
</details>

**Bài toán thực tế 3.2:** Số điểm 10 của ba bạn An, Bình, Cường tỉ lệ với 2, 3, 4. Biết rằng bình phương số điểm của An cộng với bình phương số điểm của Bình bằng 117. Tính số điểm 10 của mỗi bạn.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Gọi số điểm 10 của An, Bình, Cường là $a,b,c$. $\dfrac{a}{2} = \dfrac{b}{3} = \dfrac{c}{4} = k \Rightarrow a=2k, b=3k$.
$a^2 + b^2 = 4k^2 + 9k^2 = 13k^2 = 117 \Rightarrow k^2 = 9$. Vì số điểm $>0$ nên $k=3$.
$a = 6, b = 9, c = 12$.
</details>

**Bài toán thực tế 3.3:** Một hình chữ nhật có chu vi là 56 m. Biết tỉ số giữa chiều dài và chiều rộng là $4 : 3$. Tính diện tích hình chữ nhật đó.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>
Nửa chu vi là $56 : 2 = 28$ (m).
Gọi chiều dài và chiều rộng là $a, b$. Ta có $\dfrac{a}{4} = \dfrac{b}{3}$ và $a + b = 28$.
$\dfrac{a}{4} = \dfrac{b}{3} = \dfrac{28}{7} = 4 \Rightarrow a = 16, b = 12$.
Diện tích là $16 \cdot 12 = 192$ ($m^2$).
</details>
