### 📐 Lý thuyết & Kiến thức trọng tâm

#### 1. Phép cộng phân thức đại số

- **Cùng mẫu thức:** Muốn cộng hai phân thức có cùng mẫu thức, ta cộng các tử thức với nhau và giữ nguyên mẫu thức:
$$\dfrac{A}{M} + \dfrac{B}{M} = \dfrac{A + B}{M}$$
- **Khác mẫu thức:** Muốn cộng hai phân thức có mẫu thức khác nhau, ta quy đồng mẫu thức rồi cộng các phân thức có cùng mẫu thức vừa tìm được.
- **Tính chất:** Phép cộng phân thức có các tính chất:
  - Giao hoán: $\dfrac{A}{B} + \dfrac{C}{D} = \dfrac{C}{D} + \\dfrac{A}{B}$
  - Kết hợp: $\left(\dfrac{A}{B} + \dfrac{C}{D}\right) + \dfrac{E}{F} = \dfrac{A}{B} + \left(\dfrac{C}{D} + \dfrac{E}{F}\right)$

**Ví dụ 1:** Tính $\dfrac{3x - 1}{x + 1} + \dfrac{2x + 6}{x + 1}$.  
*Lời giải:* $\dfrac{(3x - 1) + (2x + 6)}{x + 1} = \dfrac{5x + 5}{x + 1} = \dfrac{5(x + 1)}{x + 1} = 5$.

**Ví dụ 2:** Tính $\dfrac{1}{x - 2} + \dfrac{1}{x + 2}$.  
*Lời giải:* $MTC = (x - 2)(x + 2) = x^2 - 4$.  
$\dfrac{x + 2}{(x - 2)(x + 2)} + \dfrac{x - 2}{(x - 2)(x + 2)} = \dfrac{(x + 2) + (x - 2)}{x^2 - 4} = \dfrac{2x}{x^2 - 4}$.

**Ví dụ 3:** Tính nhanh $S = \dfrac{1}{x(x + 1)} + \dfrac{1}{(x + 1)(x + 2)}$.  
*Lời giải:* Áp dụng tách $\dfrac{1}{x(x+1)} = \dfrac{1}{x} - \dfrac{1}{x+1} \Rightarrow S = \dfrac{1}{x} - \dfrac{1}{x+1} + \dfrac{1}{x+1} - \dfrac{1}{x+2} = \dfrac{1}{x} - \dfrac{1}{x+2} = \dfrac{2}{x(x + 2)}$.

#### 2. Phân thức đối & Phép trừ phân thức đại số

- **Phân thức đối:** Phân thức đối của $\dfrac{A}{B}$ ký hiệu là $-\dfrac{A}{B}$. Ta có $-\dfrac{A}{B} = \dfrac{-A}{B} = \dfrac{A}{-B}$.
- **Phép trừ:** Muốn trừ phân thức $\dfrac{A}{B}$ cho phân thức $\dfrac{C}{D}$, ta cộng $\dfrac{A}{B}$ với phân thức đối của $\dfrac{C}{D}$:
$$\dfrac{A}{B} - \dfrac{C}{D} = \dfrac{A}{B} + \left(-\dfrac{C}{D}\right)$$

**Ví dụ 1:** Thực hiện phép tính $\dfrac{x + 3}{x - 1} - \dfrac{4}{x - 1}$.  
*Lời giải:* $\dfrac{x + 3 - 4}{x - 1} = \dfrac{x - 1}{x - 1} = 1$.

**Ví dụ 2:** Thực hiện phép tính $\dfrac{x}{x - 3} - \dfrac{9}{x(x - 3)}$.  
*Lời giải:* $MTC = x(x - 3)$.  
$\dfrac{x^2 - 9}{x(x - 3)} = \dfrac{(x - 3)(x + 3)}{x(x - 3)} = \dfrac{x + 3}{x}$.

**Ví dụ 3:** Thực hiện phép tính $\dfrac{x^2 + 2}{x^3 - 1} - \dfrac{1}{x - 1}$.  
*Lời giải:* $x^3 - 1 = (x - 1)(x^2 + x + 1) \Rightarrow MTC = (x - 1)(x^2 + x + 1)$.  
$\dfrac{x^2 + 2 - (x^2 + x + 1)}{(x - 1)(x^2 + x + 1)} = \dfrac{1 - x}{(x - 1)(x^2 + x + 1)} = \dfrac{-(x - 1)}{(x - 1)(x^2 + x + 1)} = \dfrac{-1}{x^2 + x + 1}$.
