### 📐 Lý thuyết & Kiến thức trọng tâm

#### 1. Phép nhân phân thức đại số

- **Quy tắc:** Muốn nhân hai phân thức, ta nhân các tử thức với nhau và nhân các mẫu thức với nhau:
$$\dfrac{A}{B} \\cdot \\dfrac{C}{D} = \\dfrac{A \\cdot C}{B \\cdot D}$$
- **Tính chất:**
  - Giao hoán: $\\dfrac{A}{B} \\cdot \\dfrac{C}{D} = \\dfrac{C}{D} \\cdot \\dfrac{A}{B}$
  - Kết hợp: $\\left(\\dfrac{A}{B} \\cdot \\dfrac{C}{D}\\right) \\cdot \\dfrac{E}{F} = \\dfrac{A}{B} \\cdot \\left(\\dfrac{C}{D} \\cdot \\dfrac{E}{F}\\right)$
  - Phân phối đối với phép cộng: $\\dfrac{A}{B}\\left(\\dfrac{C}{D} + \\dfrac{E}{F}\\right) = \\dfrac{A}{B} \\cdot \\dfrac{C}{D} + \\dfrac{A}{B} \\cdot \\dfrac{E}{F}$

**Ví dụ 1:** Thực hiện phép tính $\\dfrac{3x}{x + 1} \\cdot \\dfrac{x^2 - 1}{6x^2}$.  
*Lời giải:* $\\dfrac{3x \cdot (x - 1)(x + 1)}{(x + 1) \cdot 6x^2} = \\dfrac{x - 1}{2x}$.

**Ví dụ 2:** Tính nhanh $A = \\dfrac{x^2 - 4}{x + 3} \\cdot \\dfrac{x + 3}{x - 2}$.  
*Lời giải:* $\\dfrac{(x - 2)(x + 2)(x + 3)}{(x + 3)(x - 2)} = x + 2$.

**Ví dụ 3:** Thực hiện phép tính $\\dfrac{x - 1}{x} \\cdot \\left(\\dfrac{x + 1}{x - 1} + \\dfrac{1}{x - 1}\\right)$.  
*Lời giải:* $=\\dfrac{x - 1}{x} \\cdot \\dfrac{x + 2}{x - 1} = \\dfrac{x + 2}{x}$.

#### 2. Phân thức nghịch đảo & Phép chia phân thức đại số

- **Phân thức nghịch đảo:** Phân thức $\\dfrac{B}{A}$ được gọi là phân thức nghịch đảo của phân thức $\\dfrac{A}{B}$ (với $A, B$ là các đa thức khác 0).
- **Quy tắc chia:** Muốn chia phân thức $\\dfrac{A}{B}$ cho phân thức $\\dfrac{C}{D}$ khác 0, ta nhân $\\dfrac{A}{B}$ với phân thức nghịch đảo của $\\dfrac{C}{D}$:
$$\\dfrac{A}{B} : \\dfrac{C}{D} = \\dfrac{A}{B} \\cdot \\dfrac{D}{C} = \\dfrac{A \\cdot D}{B \\cdot C}$$

**Ví dụ 1:** Thực hiện phép chia $\\dfrac{x + 2}{x - 1} : \\dfrac{x + 2}{x + 3}$.  
*Lời giải:* $\\dfrac{x + 2}{x - 1} \\cdot \\dfrac{x + 3}{x + 2} = \\dfrac{x + 3}{x - 1}$.

**Ví dụ 2:** Thực hiện phép chia $\\dfrac{x^2 - 9}{x + 2} : (x - 3)$.  
*Lời giải:* $\\dfrac{(x - 3)(x + 3)}{x + 2} \\cdot \\dfrac{1}{x - 3} = \\dfrac{x + 3}{x + 2}$.

**Ví dụ 3:** Rút gọn biểu thức $B = \\dfrac{x}{x - 1} : \\dfrac{x + 1}{x - 1} : \\dfrac{x}{x + 1}$.  
*Lời giải:* $B = \\dfrac{x}{x - 1} \\cdot \\dfrac{x - 1}{x + 1} \\cdot \\dfrac{x + 1}{x} = 1$.

a) Viết phân thức biểu thị tỉ số giữa thời gian ngược dòng $T_{\text{ngược}}$ và thời gian xuôi dòng $T_{\text{xuôi}}$.
