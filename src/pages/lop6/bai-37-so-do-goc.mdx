<h3 id="so-do-goc">📖 1. Số đo góc</h3>

<div class="box-dinh-nghia">

**Số đo góc** là một số dương, được tính bằng đơn vị độ (°).

**Ký hiệu:** Số đo góc AOB được ký hiệu là ∠AOB hoặc m(∠AOB)

**Đơn vị:** Độ (°), phút ('), giây ('')

</div>

**Các góc đặc biệt:**
- Góc nhọn: 0° < ∠ < 90°
- Góc vuông: ∠ = 90°
- Góc tù: 90° < ∠ < 180°
- Góc bẹt: ∠ = 180°

<h3 id="cach-do-goc" style="margin-top:2rem;">📖 2. Cách đo góc</h3>

**Dụng cụ:** Thước đo góc (thước đo độ)

**Các bước đo góc AOB:**

1. Đặt tâm của thước trùng với đỉnh O của góc
2. Đặt cạnh của thước trùng với cạnh OA
3. Đọc số đo trên thước tại vị trí cạnh OB

<h3 id="so-sanh-goc" style="margin-top:2rem;">📖 3. So sánh góc</h3>

**Cách so sánh:**

1. Đo số đo của từng góc
2. So sánh các số đo

**Ký hiệu so sánh:**
- ∠AOB = ∠COD (bằng nhau)
- ∠AOB < ∠COD (nhỏ hơn)
- ∠AOB > ∠COD (lớn hơn)

**Ví dụ:**

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

- ∠AOB = 45°
- ∠COD = 60°
- ∠EOF = 90°

So sánh: ∠AOB < ∠COD < ∠EOF

</div>

<h3 id="vi-du-tinh-toan" style="margin-top:2rem;">📖 6. Ví dụ tính toán</h3>

**Ví dụ 1:** Cho ∠AOB = 60°, ∠BOC = 30°, tia OB nằm giữa OA và OC. Tính ∠AOC.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**
∠AOC = ∠AOB + ∠BOC = 60° + 30° = 90°

Vậy ∠AOC là góc vuông.

</div>

**Ví dụ 2:** Cho ∠AOC = 120°, ∠AOB = 50°, tia OB nằm giữa OA và OC. Tính ∠BOC.

<div style="background:#dbeafe;border-left:4px solid #1e40af;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**
∠BOC = ∠AOC - ∠AOB = 120° - 50° = 70°

Vậy ∠BOC là góc nhọn.

</div>

**Ví dụ 3:** Cho ∠AOB = 45°, ∠BOC = 45°, tia OB nằm giữa OA và OC. Tính ∠AOC.

<div style="background:#fef3c7;border-left:4px solid #f59e0b;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**
∠AOC = ∠AOB + ∠BOC = 45° + 45° = 90°

Vậy ∠AOC là góc vuông.

**📝 Bài toán 1:** Một chiếc đồng hồ chỉ 3 giờ. Hãy xác định:

a) Góc giữa kim giờ và kim phút là bao nhiêu độ?

b) Góc này là **góc vuông**

c) Lúc 6 giờ, góc giữa hai kim là **180°** (góc bẹt)

</div>

**📝 Bài toán 2:** Một chiếc thang dựa vào tường. Góc giữa thang và mặt đất là 60°. Hãy xác định:

b) Góc giữa thang và tường là góc gì?

c) Nếu góc giữa thang và mặt đất là 45°, góc giữa thang và tường là bao nhiêu độ?

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

b) Góc này là **góc nhọn**

c) Góc giữa thang và tường = 90° - 45° = **45°**

</div>

**📝 Bài toán 3:** Cho ba tia OA, OB, OC chung gốc O. Biết ∠AOB = 40°, ∠BOC = 35°, ∠AOC = 75°.

a) Xác định tia nào nằm giữa hai tia còn lại.

b) Tính góc lớn nhất trong ba góc.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

**Giải:**

a) Vì ∠AOB + ∠BOC = 40° + 35° = 75° = ∠AOC nên tia OB nằm giữa tia OA và tia OC.

b) Góc lớn nhất là ∠AOC = **75°**

</div>

**Câu 2:** Góc vuông có số đo **90°**

**Câu 5:** ∠AOC = ∠AOB + ∠BOC = 40° + 50° = **90°**

**Câu 6:** ∠BOC = ∠AOC - ∠AOB = 120° - 45° = **75°**

**Câu 7:** Mỗi giờ trên đồng hồ tương ứng với góc 360°/12 = 30°. Lúc 2 giờ: 2 × 30° = **60°**

**Câu 8:** Gọi ∠BOC = x thì ∠AOC = 3x. Ta có: 3x + x = 90° → 4x = 90° → x = 22,5°. Vậy ∠BOC = 22,5°, ∠AOC = 3 × 22,5° = **67,5°**

**Câu 10:** Gọi ∠COB = x thì ∠AOC = 2x. Ta có: 2x + x = 120° → 3x = 120° → x = 40°. Vậy ∠AOC = 2 × 40° = **80°**
