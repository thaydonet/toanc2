<KhamPha>

<h3 id="cong-da-thuc">📖 1. Phép cộng đa thức</h3>

<div class="box-dinh-ly">

**Quy tắc:** Để cộng hai đa thức, ta:

1. Bỏ dấu ngoặc
2. Nhóm các hạng tử đồng dạng (cùng bậc)
3. Cộng các hạng tử đồng dạng
4. Thu gọn kết quả

</div>

**Ví dụ 1:** Cho $P(x) = 3x^2 - 2x + 5$ và $Q(x) = x^2 + 4x - 3$. Tính $P(x) + Q(x)$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

$P(x) + Q(x) = (3x^2 - 2x + 5) + (x^2 + 4x - 3)$

$= 3x^2 - 2x + 5 + x^2 + 4x - 3$

$= (3x^2 + x^2) + (-2x + 4x) + (5 - 3)$

$= 4x^2 + 2x + 2$

</div>

<h3 id="tru-da-thuc" style="margin-top:2rem;">📖 2. Phép trừ đa thức</h3>

<div class="box-dinh-ly">

**Quy tắc:** Để trừ hai đa thức, ta:

1. Đổi dấu tất cả các hạng tử của đa thức bị trừ
2. Cộng đa thức thứ nhất với đa thức đối của đa thức thứ hai

$$P(x) - Q(x) = P(x) + (-Q(x))$$

</div>

**Ví dụ 2:** Cho $P(x) = 5x^2 - 3x + 1$ và $Q(x) = 2x^2 + x - 4$. Tính $P(x) - Q(x)$.

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

$P(x) - Q(x) = (5x^2 - 3x + 1) - (2x^2 + x - 4)$

$= 5x^2 - 3x + 1 - 2x^2 - x + 4$

$= (5x^2 - 2x^2) + (-3x - x) + (1 + 4)$

$= 3x^2 - 4x + 5$

</div>

<h3 id="da-thuc-doi" style="margin-top:2rem;">📖 3. Đa thức đối</h3>

<div class="box-dinh-nghia">

**Đa thức đối** của $P(x)$ là $-P(x)$, được tạo bằng cách đổi dấu tất cả các hạng tử.

$$P(x) + (-P(x)) = 0$$

</div>

**Ví dụ 3:** Tìm đa thức đối của $P(x) = 3x^2 - 5x + 2$

<div style="background:#f0f9ff;border-left:4px solid #0ea5e9;border-radius:8px;padding:1rem 1.25rem;margin:1rem 0;">

$-P(x) = -(3x^2 - 5x + 2) = -3x^2 + 5x - 2$

</div>

<h3 id="tinh-chat" style="margin-top:2rem;">📖 4. Tính chất</h3>

<div class="box-dinh-ly">

**Tính chất giao hoán:** $P(x) + Q(x) = Q(x) + P(x)$

**Tính chất kết hợp:** $[P(x) + Q(x)] + R(x) = P(x) + [Q(x) + R(x)]$

**Cộng với 0:** $P(x) + 0 = P(x)$

**Cộng với đa thức đối:** $P(x) + (-P(x)) = 0$

</div>

</KhamPha>

<VanDung title="II. Các dạng toán và Phương pháp giải">

<h3 id="cac-dang-toan">🧩 II. Các dạng toán và Phương pháp giải</h3>

<h4 id="dang-1">Dạng 1: Cộng, trừ hai đa thức một biến</h4>

**Phương pháp:** 
- **Cách 1 (Hàng ngang):** Bỏ dấu ngoặc (đổi dấu các hạng tử nếu có dấu trừ đằng trước), nhóm các hạng tử đồng dạng và thu gọn.
- **Cách 2 (Cột dọc):** Sắp xếp hai đa thức theo lũy thừa giảm dần, đặt các hạng tử cùng bậc ở cùng một cột dọc rồi thực hiện cộng hoặc trừ các hệ số.

**Ví dụ 1.1:** Cho $P(x) = 3x^3 - 2x^2 + x - 5$ và $Q(x) = -x^3 + 2x^2 + 3x + 1$. Tính $P(x) + Q(x)$ và $P(x) - Q(x)$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>

- $P(x) + Q(x) = (3x^3 - x^3) + (-2x^2 + 2x^2) + (x + 3x) + (-5 + 1) = 2x^3 + 4x - 4$.
- $P(x) - Q(x) = (3x^3 - (-x^3)) + (-2x^2 - 2x^2) + (x - 3x) + (-5 - 1) = 4x^3 - 4x^2 - 2x - 6$.

</details>

---

<h4 id="dang-2">Dạng 2: Tìm đa thức chưa biết trong đẳng thức cộng trừ</h4>

**Phương pháp:** Dùng quy tắc chuyển vế:
- Nếu $A(x) + B(x) = C(x) \Rightarrow A(x) = C(x) - B(x)$.
- Nếu $A(x) - B(x) = C(x) \Rightarrow A(x) = C(x) + B(x)$.

**Ví dụ 2.1:** Tìm đa thức $A(x)$ biết $A(x) + (2x^2 - 3x + 1) = 5x^2 + 2x - 4$.

<details style="margin:0.5rem 0 1rem;padding:0.75rem 1rem;background:#f0f4ff;border-radius:8px;border:1px solid #a5b4fc;">
<summary style="cursor:pointer;font-weight:600;color:#4338ca;">Lời giải</summary>

$$A(x) = (5x^2 + 2x - 4) - (2x^2 - 3x + 1) = 5x^2 + 2x - 4 - 2x^2 + 3x - 1 = 3x^2 + 5x - 5$$

</details>
