<h3 id="cong-da-thuc">📖 1. Phép cộng hai đa thức</h3>

<div class="box-dinh-nghia">

**Quy tắc cộng hai đa thức:**
1. Viết hai đa thức trong dấu ngoặc nối với nhau bởi dấu $+$.
2. Bỏ dấu ngoặc (giữ nguyên dấu của các hạng tử).
3. Nhóm các hạng tử đồng dạng và thu gọn.

</div>

**Ví dụ 1:** Cho $A = 3x^2y - 2xy + 5$ và $B = 2x^2y + 5xy - 3$. Tính $A + B$.

*Lời giải:*
$$A + B = (3x^2y - 2xy + 5) + (2x^2y + 5xy - 3)$$
$$= 3x^2y - 2xy + 5 + 2x^2y + 5xy - 3$$
$$= (3x^2y + 2x^2y) + (-2xy + 5xy) + (5 - 3) = 5x^2y + 3xy + 2$$

**Ví dụ 2:** Tính tổng hai đa thức $P = x^3 - 3x^2 + x$ và $Q = 2x^2 - x + 4$.

*Lời giải:*
$$P + Q = (x^3 - 3x^2 + x) + (2x^2 - x + 4)$$
$$= x^3 + (-3x^2 + 2x^2) + (x - x) + 4 = x^3 - x^2 + 4$$

**Ví dụ 3:** Cho $M = a^2 - 2ab + b^2$ và $N = a^2 + 2ab + b^2$. Tính $M + N$.

*Lời giải:*
$$M + N = (a^2 - 2ab + b^2) + (a^2 + 2ab + b^2) = 2a^2 + 2b^2$$

<h3 id="tru-da-thuc" style="margin-top:2rem;">➖ 2. Phép trừ hai đa thức</h3>

<div class="box-dinh-nghia">

**Quy tắc trừ hai đa thức:**
1. Viết hai đa thức trong dấu ngoặc nối với nhau bởi dấu $-$.
2. Bỏ dấu ngoặc: **đổi dấu tất cả các hạng tử** của đa thức nằm sau dấu $-$.
3. Nhóm các hạng tử đồng dạng và thu gọn.

</div>

**Ví dụ 1:** Cho $A = 5x^2y - 2xy + 3$ và $B = 2x^2y + 4xy - 1$. Tính $A - B$.

*Lời giải:*
$$A - B = (5x^2y - 2xy + 3) - (2x^2y + 4xy - 1)$$
$$= 5x^2y - 2xy + 3 - 2x^2y - 4xy + 1$$
$$= (5x^2y - 2x^2y) + (-2xy - 4xy) + (3 + 1) = 3x^2y - 6xy + 4$$

**Ví dụ 2:** Cho $P = x^3 + 2x^2 - x + 5$ và $Q = x^3 - 3x + 2$. Tính $P - Q$.

*Lời giải:*
$$P - Q = (x^3 + 2x^2 - x + 5) - (x^3 - 3x + 2)$$
$$= x^3 + 2x^2 - x + 5 - x^3 + 3x - 2$$
$$= (x^3 - x^3) + 2x^2 + (-x + 3x) + (5 - 2) = 2x^2 + 2x + 3$$

**Ví dụ 3:** Tìm đa thức $C$ biết $C + (2x^2 - y) = 5x^2 + 3y$.

*Lời giải:*
$$C = (5x^2 + 3y) - (2x^2 - y) = 5x^2 + 3y - 2x^2 + y = 3x^2 + 4y$$

<h3 id="cac-dang-toan" style="display:none">Các dạng toán</h3>

<div class="box-dinh-ly">

**Dạng 1: Tính tổng và hiệu của hai đa thức**

</div>

**Ví dụ 1:** Cho $A = 2x^2 - 3xy + y^2$ và $B = x^2 + 2xy - 3y^2$. Tính $A + B$ và $A - B$.

*Lời giải:*
- $A + B = 3x^2 - xy - 2y^2$.
- $A - B = x^2 - 5xy + 4y^2$.

**Ví dụ 2:** Tính $(3x^3 - 2x^2 + 5) + (x^3 + 2x^2 - 4x + 1)$.

*Lời giải:* $4x^3 - 4x + 6$.

**Ví dụ 3:** Tính $(5a^2b - 3ab^2) - (2a^2b - 5ab^2)$.

*Lời giải:* $3a^2b + 2ab^2$.

<div class="box-dinh-ly" style="margin-top:2rem;">

**Dạng 2: Tìm đa thức chưa biết trong một đẳng thức**

</div>

**Ví dụ 1:** Tìm $M$ biết $M + (x^2 - 3y^2) = 4x^2 + 2y^2$.

*Lời giải:* $M = (4x^2 + 2y^2) - (x^2 - 3y^2) = 3x^2 + 5y^2$.

**Ví dụ 2:** Tìm $N$ biết $(5x^2 - 2xy) - N = 2x^2 + 3xy$.

*Lời giải:* $N = (5x^2 - 2xy) - (2x^2 + 3xy) = 3x^2 - 5xy$.

**Ví dụ 3:** Tìm $P$ biết $P - (x^3 - 2x + 1) = 3x^2 + x - 4$.

*Lời giải:* $P = (3x^2 + x - 4) + (x^3 - 2x + 1) = x^3 + 3x^2 - x - 3$.

<div class="box-dinh-ly" style="margin-top:2rem;">

**Dạng 3: Rút gọn biểu thức và tính giá trị tại giá trị cho trước của biến**

</div>

**Ví dụ 1:** Cho $A = 3x^2y - 2xy^2$ và $B = 2x^2y + 5xy^2$. Tính $A + B$ tại $x = 1, y = 2$.

*Lời giải:* $A + B = 5x^2y + 3xy^2$. Tại $x=1, y=2 \Rightarrow 5(1)(2) + 3(1)(4) = 10 + 12 = 22$.

**Ví dụ 2:** Rút gọn $P = (x^2 - y^2) - (x^2 + 2xy + y^2) + 2xy$.

*Lời giải:* $P = -2y^2$.

**Ví dụ 3:** Tính giá trị $M = (x^3 + 3x^2 + 3x + 1) - (x^3 - 1)$ tại $x = 99$.

*Lời giải:* $M = 3x^2 + 3x + 2$. Tại $x=99 \Rightarrow M = 3(99)^2 + 3(99) + 2 = 3(99)(100) + 2 = 29702$.

**📝 Câu 1 (Lợi nhuận công ty):** Doanh thu thu được của một cửa hàng trong một tháng biểu thị bởi đa thức $R(x) = 150x + 2000$ (nghìn đồng). Tổng chi phí bỏ ra biểu thị bởi $C(x) = 90x + 1200$ (nghìn đồng), với $x$ là số sản phẩm bán được.

**Lời giải:**
a) $S = S_1 - S_2 = (5x^2 + 3xy) - (2x^2 - xy + 10) = 3x^2 + 4xy - 10$ (m²).

a) Viết đa thức biểu thị tổng quãng đường hai xe đã đi.

<GhiNho>

- **Cộng hai đa thức**: $A + B = (A) + (B)$, bỏ ngoặc giữ nguyên dấu, thu gọn.
- **Trừ hai đa thức**: $A - B = (A) - (B)$, bỏ ngoặc **đổi dấu toàn bộ hạng tử** của $B$, thu gọn.
- **Tìm đa thức chưa biết**:
  - $X + B = A \Rightarrow X = A - B$.
  - $A - X = B \Rightarrow X = A - B$.
  - $X - A = B \Rightarrow X = A + B$.

</GhiNho>
