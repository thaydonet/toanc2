#### 1. Rút gọn và biến đổi biểu thức theo hằng đẳng thức

**Ví dụ 1:** Rút gọn $A = (x + 2)^2 + (x - 2)^2 - 2(x^2 - 4)$.  
*Lời giải:* $A = (x^2 + 4x + 4) + (x^2 - 4x + 4) - (2x^2 - 8) = 2x^2 + 8 - 2x^2 + 8 = 16$.

**Ví dụ 2:** Rút gọn $B = (x - 1)(x^2 + x + 1) - (x + 1)(x^2 - x + 1)$.  
*Lời giải:* $B = (x^3 - 1) - (x^3 + 1) = -2$.

**Ví dụ 3:** Tính nhanh $103^2 - 9$.  
*Lời giải:* $103^2 - 3^2 = (103 - 3)(103 + 3) = 100 \cdot 106 = 10600$.

---

#### 2. Phân tích đa thức thành nhân tử & Giải phương trình

**Ví dụ 1:** Phân tích $x^3 - 6x^2 + 9x$.  
*Lời giải:* $x(x^2 - 6x + 9) = x(x - 3)^2$.

**Ví dụ 2:** Phân tích $x^2 - 2xy + y^2 - 25$.  
*Lời giải:* $(x - y)^2 - 5^2 = (x - y - 5)(x - y + 5)$.

**Ví dụ 3:** Giải phương trình $x^2 - 7x + 12 = 0$.  
*Lời giải:* $x^2 - 3x - 4x + 12 = 0 \Rightarrow (x - 3)(x - 4) = 0 \Rightarrow x = 3$ hoặc $x = 4$.
