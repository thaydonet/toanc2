### 📐 Lý thuyết & Kiến thức trọng tâm

#### 1. Tổng hai lập phương

Với hai biểu thức tùy ý $A$ và $B$, ta có:
$$A^3 + B^3 = (A + B)(A^2 - AB + B^2)$$

*(Lưu ý: Ta gọi $A^2 - AB + B^2$ là bình phương thiếu của một hiệu).*

</svg>
<p style="font-size:0.9rem;color:#475569;margin-top:0.5rem;"><em>Hình 1: Mô hình ghép tổng hai thể tích lập phương $A^3 + B^3$</em></p>
</div>

**Ví dụ 1:** Khai triển $x^3 + 27$.  
*Lời giải:* $x^3 + 27 = x^3 + 3^3 = (x + 3)(x^2 - 3x + 9)$.

**Ví dụ 2:** Viết tích $(2x + y)(4x^2 - 2xy + y^2)$ dưới dạng tổng hai lập phương.  
*Lời giải:* $(2x + y)[(2x)^2 - (2x)y + y^2] = (2x)^3 + y^3 = 8x^3 + y^3$.

**Ví dụ 3:** Tính nhanh $1001 \cdot 999$ bằng hằng đẳng thức tổng lập phương.  
*Lời giải:* $(10 + 1)(100 - 10 + 1) = 10^3 + 1^3 = 1001$.

---

#### 2. Hiệu hai lập phương

Với hai biểu thức tùy ý $A$ và $B$, ta có:
$$A^3 - B^3 = (A - B)(A^2 + AB + B^2)$$

*(Lưu ý: Ta gọi $A^2 + AB + B^2$ là bình phương thiếu của một tổng).*

**Ví dụ 1:** Khai triển $x^3 - 64$.  
*Lời giải:* $x^3 - 64 = x^3 - 4^3 = (x - 4)(x^2 + 4x + 16)$.

**Ví dụ 2:** Viết tích $(3x - 1)(9x^2 + 3x + 1)$ dưới dạng hiệu hai lập phương.  
*Lời giải:* $(3x - 1)[(3x)^2 + 3x \cdot 1 + 1^2] = (3x)^3 - 1^3 = 27x^3 - 1$.

**Ví dụ 3:** Tính nhanh $999$ dưới dạng tích hằng đẳng thức.  
*Lời giải:* $(10 - 1)(100 + 10 + 1) = 10^3 - 1^3 = 1000 - 1 = 999$.

</div>

**Ví dụ 1:** Rút gọn $A = (x - 1)(x^2 + x + 1) - x^3$.

**Ví dụ 2:** Rút gọn $B = (x + 2)(x^2 - 2x + 4) - (x - 2)(x^2 + 2x + 4)$.  
*Lời giải:* $B = (x^3 + 8) - (x^3 - 8) = 16$.

**Ví dụ 3:** Tính giá trị $P = (x + 3)(x^2 - 3x + 9)$ tại $x = 10$.  
*Lời giải:* $P = x^3 + 27 = 10^3 + 27 = 1027$.

**Bài 2 (Dễ — Viết dưới dạng tổng hoặc hiệu hai lập phương):** Viết các tích sau dưới dạng tổng hoặc hiệu hai lập phương:

a) $(x + 2)(x^2 - 2x + 4)$ &nbsp;&nbsp;&nbsp; b) $(x - 3)(x^2 + 3x + 9)$

c) $(2x + 1)(4x^2 - 2x + 1)$ &nbsp;&nbsp;&nbsp; d) $(3x - 2y)(9x^2 + 6xy + 4y^2)$

**Bài 3 (Trung bình — Rút gọn & Tính giá trị biểu thức):**

a) Tính giá trị $A = (x - 1)(x^2 + x + 1)$ tại $x = 10$.

b) Tính giá trị $B = (x + 3)(x^2 - 3x + 9)$ tại $x = 7$.

c) Tính giá trị $C = (2x - y)(4x^2 + 2xy + y^2)$ tại $x = 3, y = 2$.

d) Rút gọn $P = (x - 2)(x^2 + 2x + 4) - x^3$.

e) Rút gọn $Q = (x + 1)(x^2 - x + 1) + (x - 1)(x^2 + x + 1)$.

f) Rút gọn $M = (x + 2)(x^2 - 2x + 4) - (x - 2)(x^2 + 2x + 4)$.

**Bài 4 (Trung bình — Tìm $x$):**

a) Tìm $x$ biết $(x + 2)(x^2 - 2x + 4) - x^3 = 2x$.

b) Tìm $x$ biết $(x - 1)(x^2 + x + 1) - x^3 = -x$.

c) Tìm $x$ biết $x^3 + 27 = 0$.

**Bài 5 (Trung bình — Chứng minh đẳng thức):**

a) Chứng minh $(a + b)(a^2 - ab + b^2) + (a - b)(a^2 + ab + b^2) = 2a^3$.

b) Chứng minh $(a + b)^3 - (a - b)^3 = 2b(3a^2 + b^2)$.

**Bài 6 (Khá — Chứng minh biểu thức không phụ thuộc biến):**

a) Chứng minh $P = (x + 2)(x^2 - 2x + 4) - (x - 1)(x^2 + x + 1) = 9$ có giá trị không phụ thuộc vào $x$.

b) Chứng minh $Q = (x - y)(x^2 + xy + y^2) + (y - z)(y^2 + yz + z^2) + (z - x)(z^2 + zx + x^2) = 0$.

**Bài 7 (Khá — Cho $x+y$ và $xy$, tính $x^3+y^3$):**

a) Cho $x + y = 4$ và $xy = 3$. Tính $x^3 + y^3$.

b) Cho $x - y = 5$ và $xy = 2$. Tính $x^3 - y^3$.

**Bài 8 (Khá - Nâng cao — Chứng minh biểu thức luôn dương):**

a) Chứng minh $A = x^2 - x + 1 > 0$ với mọi $x \in \mathbb{R}$ (Bình phương thiếu của một hiệu).

b) Chứng minh $B = x^2 + x + 1 > 0$ với mọi $x \in \mathbb{R}$ (Bình phương thiếu của một tổng).

**Bài 9 (Ứng dụng thực tế 1 — Thể tích bể bơi ghép):** Bể bơi A dạng hình lập phương cạnh $x$ (m), bể bơi B dạng hình lập phương cạnh $y$ (m).

b) Tính tổng thể tích hai bể khi $x = 4$ m, $y = 3$ m.

**Bài 10 (Ứng dụng thực tế 2 — Lượng nước chênh lệch):** Một thùng chứa hình lập phương lớn cạnh $a$ (m) và thùng nhỏ cạnh $b$ (m).
